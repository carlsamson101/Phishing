# Phishing Simulation

A web-based **Phishing Simulation and Awareness Platform** designed to demonstrate common phishing techniques and help users recognize suspicious messages, links, and requests.

The project provides an interactive environment where users can experience simulated phishing scenarios and learn how to identify common warning signs before taking potentially risky actions.

## Features

* Interactive phishing simulation scenarios
* Phishing awareness and identification activities
* User interaction and response tracking
* Database storage using **Supabase**
* Responsive web interface
* Deployed and accessible through **Netlify**
* Designed for educational and cybersecurity awareness purposes

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Database:** Supabase
* **Deployment:** Netlify
* **Version Control:** Git & GitHub

## How It Works

The application presents users with simulated phishing scenarios designed to resemble common online threats. User interactions and results are stored in the Supabase database, allowing the system to record and evaluate responses.

The application is deployed through Netlify, providing a publicly accessible web environment for testing and demonstration.

## Purpose

This project was developed as an educational tool to improve awareness of phishing attacks and demonstrate how users can identify suspicious online activities. It does **not** perform real phishing attacks or attempt to obtain real user credentials.

## Deployment

The application is deployed using **Netlify**, while **Supabase** is used as the backend database for storing application data.
